- `az ~0.986g, ax ~-0.024g, ay ~+0.016g` -> Roll_acc ~0.94 deg, Pitch_acc ~1.40 deg (mat ban hoi nghieng).

- `std rpacc ~0.065 deg`, `std pcf/pkf ~0.016-0.017 deg`.
- Gyro-only tich phan sau calib: drift ~-0.05 deg / 8s (se do lai drift 5 phut o PHASE 12).

## 4. Exec time (DWT, ca burst I2C + thuat toan)

- `Tproc < Ts=2000us`, margin ~1.3ms. I2C 400kHz burst chiem phan lon, thuat toan float nhe.
- Can tach benchmark tung khoi (Acc/Gyro/CF/Kalman) + jitter sampling o buoc sau.
